# المحتوى المشترك

هذا المجلد هو مصدر البيانات الوحيد. الملزمة ومنصة الألعاب والحلقات اليومية تقرأ منه، فأي تصحيح هنا يظهر في الثلاثة.

## `terms/unit-NN.json` — مصطلحات كل فصل

```json
{
  "id": "unit-01",
  "unit": 1,
  "title_ar": "المادة وخواصها",
  "title_en": "Matter and Its Properties",
  "status": "draft | reviewed",
  "terms": [
    {
      "id": "matter",
      "en": "Matter",
      "ar": "المادة",
      "def_ar": "التعريف بالعربية",
      "def_en": "Definition in English",
      "example_ar": "مثال قصير",
      "emoji": "🧱"
    }
  ]
}
```

- `id` فريد في كل الملفات، بحروف إنكليزية صغيرة وشرطات.
- ترتيب الفصول والمصطلحات هو ترتيب الحلقات.
- `status: reviewed` بعد مطابقة الفصل مع الكتاب المدرسي.

## `episodes/YYYY-MM-DD.json` — حلقة يوم محدد (اختياري)

إذا وُجد ملف بتاريخ اليوم استُعمل، وإلا تُبنى الحلقة تلقائياً من المصطلحات التالية بالترتيب.

```json
{
  "title": "المادة والكتلة والحجم",
  "terms": ["matter", "mass", "volume"],
  "hook": "جملة افتتاحية قصيرة تشد الطالب",
  "quiz": {
    "question": "ما المصطلح الذي يعني: مقدار ما يحتويه الجسم من مادة؟",
    "choices": ["Volume", "Mass", "Density"],
    "answer": 1
  },
  "youtube_title": "عنوان اليوتيوب (أقل من 100 حرف)",
  "description": "وصف اليوتيوب",
  "caption": "نص المنشور لفيسبوك وإنستغرام وتليغرام",
  "tags": ["علوم", "الأول المتوسط"]
}
```

كل الحقول اختيارية عدا `terms`.
