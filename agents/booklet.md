# وكيل الملزمة — ملزمة المصطلحات العلمية

## الهدف
ملزمة **المصطلحات العلمية** لمادة العلوم، **الصف الأول المتوسط – مدارس المتميزين**، المنهج العراقي، العام الدراسي 2026–2027.
لكل مصطلح: المصطلح بالإنكليزية، وما يقابله بالعربية، وتعريف دقيق مطابق لصياغة الكتاب، ومثال قصير.

## ما تملكه
- `content/terms/unit-NN.json`: بيانات المصطلحات بالمخطط الموجود في `content/README.md`. منصة الألعاب والحلقات اليومية تقرأ منه، فلا تغيّر المخطط ولا الـ `id` لمصطلح موجود.
- `booklet/`: مصدر الملزمة (HTML) وخريطة المنهج.
- الملزمة المنشورة كـ Artifact باسم «ملزمة المصطلحات العلمية – الأول المتوسط».

لا تعدّل خارج هذين المجلدين.

## الخطوات
1. **خريطة المنهج** (أول جلسة): ابحث عن فهرس كتاب العلوم للأول المتوسط (الطبعة الحالية) ولغة تدريسه في مدارس المتميزين، واكتب `booklet/curriculum-map.md`: الفصول والدروس وعدد المصطلحات المتوقع لكل درس، مع المصادر. ما لا تستطيع التحقق منه اكتبه سؤالاً في `docs/questions.md` (تذكير الصباح يعرضه على المعلم).
2. **المصطلحات**: كل جلسة يومية = درس واحد تقريباً. أضف مصطلحاته إلى ملف الفصل بالترتيب، بحالة `draft`. الملف `unit-01.json` الحالي مسودة أولية كُتبت لتشغيل الحلقات؛ طابقه مع الكتاب وصحّحه أولاً.
3. **الملزمة**: استعمل هوية «ملزمة القمة في الفيزياء» نفسها (https://claude.ai/artifact/7zVrbsj4B3CWBnTYZ9JnLf، اقرأها بأداة Artifact): صفحات A4، الغلاف، الفهرس، دليل الألوان. لكل فصل:
   - جدول المصطلحات (ت، المصطلح، Term، التعريف).
   - «هل تعلم؟» وملاحظة على خطأ شائع.
   - تمارين: مطابقة، أكمل الفراغ، صح وخطأ، اكتب المصطلح.
   - الأجوبة في نهاية الملزمة.
   احفظ المصدر في `booklet/` وأعد نشر الـ Artifact نفسه بعد كل فصل.
4. ملاحظات المعلم تأتي في هذه الجلسة: نفّذها أولاً قبل العمل الجديد. حين يكتب المعلم أن فصلاً روجع، غيّر `status` إلى `reviewed`.

## Git
- اعمل على الفرع الافتراضي للمستودع مباشرة. قبل كل دفع: `git pull --rebase`، وبعده `git push`.
- رسالة commit واضحة بالإنكليزية، مثل: `Booklet: add unit 2 lesson 1 terms`.
